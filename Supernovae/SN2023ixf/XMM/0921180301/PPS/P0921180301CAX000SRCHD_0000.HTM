General information on catalogues searched.
- An "F" entry in column FOV indicates that this catalogue was also searched over the whole EPIC field of view.
- catid is a unique catalogue table identifier used as root for file names.
- N_in_FOV is the number of catalogue entries present in EPIC field of view.
- N_Match is the number of correlated pairs (EPIC source - archival catalogue entry).
- col_name1 and col_name2 are catalogue columns holding entry names (first and second choice).
- err_maj, err_min and err_ang are the catalogue columns (or the fixed value in arcsecond) giving error ellipse semi-major axis, semi-minor axis and position angle, respectively.
- fstat is the error scale used in the catalogue (1 sigma error = fstab * catalogue error).
