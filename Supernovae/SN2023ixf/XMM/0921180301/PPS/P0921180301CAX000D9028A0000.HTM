Description:

    The hricat.dat table contains a list of sources detected by the
    Standard Analysis Software System (SASS) in reprocessed, public High
    Resolution Imager (HRI) datasets. In addition to the parameters
    returned by SASS (like position, count rate, signal-to-noise, etc.)
    each source in the table has associated with it a set of source and
    sequence "flags". These flags are provided by the ROSAT data centers
    in the US, Germany and the UK to help the user of the ROSHRI database
    judge the reliability of a given source.

    These data have been screened by ROSAT data centers in the US,
    Germany, and the UK as a step in the production of the Rosat Results
    Archive (RRA). The RRA contains extracted source and associated
    products with an indication of reliability for the primary parameters.

Note on SeqDetec:
    Unique name for detection, based on the observation sequence id and
    the number of the detection in the source list for that sequence.
Note on 1RXH, n_1RXH:
    this name follows IAU conventions (based on J2000 position). Note that
    this name is NOT UNIQUE, detections with the same position sharing the
    same detection name; such detections may or may not represent the same
    astrophysical source. The column n_1RXH, if not blank, gives the
    number of sources sharing the same 1RXH name (the n_1RXH column was
    added at CDS)
Note on varFlag: Source variability flag from SASS:
    N = Negative
    T = Too few observations
    P = Possible
Note on SRCflags:
    The dot (.) indicates the absence of the flag.
    c = CONFUSED    (Close sources confused detection algorithm)
    d = DET_STRUCT  (Source near detector structure)
    e = EXTENDED    (Source extended, probably resolved)
    f = FALSE_DET   (Detection of unreal or false source)
    i = INTEN_SUSP  (Source brightness suspect)
    u = UN_UNIQUE   (source matched with another source which was
                     identified in a smaller detect cell)
    m = MULT_DET    (Complex emission split into individual sources)
    n = NOT_CHECKED (Weak source below SNR threshold used for checking)
    p = POS_SUSP    (Source position suspect)
    a = ASSOCIATED  (another source nearby may influence
                     derived source quantities)
    v = VARFLG_SUSP (Source variability indicator from SASS is suspect)
    w = WITHIN_EXT  (Source within extended emission)
Note on SEQflags:
    The dot (.) indicates the absence of the flag.
    D = DEFERRED    (Field not flagged by operator)
        data screening not done
    A = ASP_SUSP    (Aspect solution suspect)
        obvious aspect problems, sources appear multiple or have
        obvious ellipticity
    B = BKG_SUSP    (Background suspect)
        Field background may be incorrect, due to inclusion of
        high background intervals or extended emission
    E = EXT_EMIS    (Extended emission in field)
        presence of extended emission over most of the field
    F = FIELD_FDET  (False detections in field)
        one or more detected sources deemed false
    M = SRC_MISS    (Sources in field missed)
    S = SLIS_MIS    (Source list missing)
        source list is missing, no sources detected by SASS or
        source detection stopped
    + = source is included in the Short Version, i.e. has the
        following flags not set (marked with a dot):
        SRCflags: f (FALSE_DET)  n (NOT_CHECKED)  u (UN_UNIQUE)
        SEQflags: D (DEFERRED)
        (the "+" flag was added at CDS)
Note on EPI:
    The Edge Proximity Indicator indicates what fraction of the detect
    cell is corrupted by edges or hot spots; a zero means no edges or hot
    spots and 1.0 means complete obscuration.
Note on unresPr:
    this number measures how well the radial distribution matches the
    expected probability function. A perfect match produces unresPr=1.0
